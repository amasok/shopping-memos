## MODIFIED Requirements

### Requirement: 商品の一覧の絞り込み

端末の DB（ゲスト・ローカルファースト）から商品の一覧を出すとき、システムは、選んでいるグループ（個人なら groupId なし）の商品だけを出し、購入済みは指定がなければ除き、タグを指定したらどれかのタグが付いた商品だけを出し、同じグループの進行中のリストにある商品と同じ名前の商品を除かなければならない（MUST）。並びは、どのモードでもサーバーと同じ作成日時の古い順にする。

#### Scenario: 選んでいるグループの商品だけを出す
- **WHEN** 個人の商品とグループ A の商品がある端末の DB で、グループ A を選んで一覧を出す
- **THEN** グループ A の商品だけが出る

#### Scenario: 購入済みの商品は指定がなければ出ない
- **WHEN** 未購入と購入済みの商品がある状態で、指定なしで一覧を出し、次に購入済みだけを指定して出す
- **THEN** 最初は未購入だけ、次は購入済みだけが出る

#### Scenario: タグを指定するとどれかのタグが付いた商品だけを出す
- **WHEN** タグ X・タグ Y・タグなしの商品がある状態で、タグ X と Y を指定して一覧を出す
- **THEN** タグ X か Y が付いた商品だけが出る

#### Scenario: 進行中のリストにある商品は一覧に出ない
- **WHEN** 同じグループの進行中のリストに「牛乳」がある状態で一覧を出す
- **THEN** 「牛乳」の商品は出ず、完了したリストにだけある商品は出る

#### Scenario: ローカルファーストの並びはサーバーと同じ作成日時の古い順
- **WHEN** ローカルファーストで、作成日時の違う 3 つの商品の一覧を出す
- **THEN** 作成日時の古い順に並ぶ

#### Scenario: ゲストの商品の並びもサーバーと同じ作成日時の古い順
- **WHEN** ゲストで、作成日時の違う 3 つの商品の一覧を出す
- **THEN** 作成日時の古い順に並ぶ

### Requirement: タグの一覧

端末の DB からタグの一覧を出すとき、システムは、選んでいるグループのタグだけを、どのモードでもサーバーと同じ名前の順に出さなければならない（MUST）。

#### Scenario: ローカルファーストのタグは選んでいるグループのものを名前の順に出す
- **WHEN** ローカルファーストで、個人のタグ「日用品」「食品」とグループ A のタグがある状態で、個人のタグの一覧を出す
- **THEN** 個人の「食品」「日用品」が名前の順に出て、グループ A のタグは出ない

#### Scenario: ゲストのタグも名前の順に出す
- **WHEN** ゲストで、タグ「日用品」「食品」「エンタメ」の一覧を出す
- **THEN** 名前の順に並ぶ
