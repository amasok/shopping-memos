## REMOVED Requirements

### Requirement: 買い物の変更の後の同期
**Reason**: O8 で、ローカルファーストの買い物も端末の DB に書くようになり、「買いたいもの」の一覧は同じ DB の変更を `useLiveQuery` でそのまま追う。tRPC の買い物の後にすぐ同期する必要がなくなった
**Migration**: サーバーファーストの `catalog.getItems` の invalidate は、「サーバーファーストの買い物の変更の後のカタログ」に移す。ローカルファーストの同期は、買い物の書き込みの後の `requestSync()`（2 秒のデバウンス）になる

## ADDED Requirements

### Requirement: サーバーファーストの買い物の変更の後のカタログ

フラグが false のログイン中に、買い物（tRPC）でリストに商品を入れる・外す、買い物を完了する、履歴を取り消す・削除すると、システムは、`catalog.getItems` のキャッシュを無効にしなければならない（MUST）。ゲストとローカルファーストでは、同じ端末の DB の変更を一覧がそのまま追うので、何もしない。

#### Scenario: サーバーファーストではカタログのキャッシュを無効にする
- **WHEN** フラグが false で、リストに商品を入れる
- **THEN** 成功の後に `catalog.getItems` のキャッシュが無効になる

#### Scenario: ローカルファーストではリストに入れた商品が一覧からすぐに消える
- **WHEN** ローカルファーストで、「買いたいもの」の一覧に出ている商品をリストに入れる
- **THEN** 同期を待たずに、その商品が一覧から消える
