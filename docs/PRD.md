# Product Requirements Document (PRD) - 買い物メモアプリ

## 1. 概要
家族やグループで共有できる買い物メモアプリ。
「買いたいもの」を登録しておき、実際の買い物時にタグ（例：「食品」「日用品」）に基づいて「買い物リスト」を一括作成するフローを特徴とする。
買い物中は「カゴに入れた」状態を管理し、最終的にまとめて「購入済み」にする。

## 2. ユーザー機能

### 2.1 ユーザー管理
- **ユーザー作成**: 新規アカウントを作成できる。
- **ログイン**: 既存のアカウントでログインできる。
- **ログアウト**: アカウントからログアウトできる。

### 2.2 グループ管理
- **グループ作成**: 家族やパートナーと共有するためのグループを作成できる。
- **共有範囲**: アイテム、タグ、リストはグループ単位で管理・共有される。

## 3. コア機能

### 3.1 買いたいもの (Shopping Items) 管理
日常的に「これ買わなきゃ」と思ったものをストックしておく機能。
- **作成**: 名前、数量などを入力して登録。グループへの紐付けが可能（作成時または後から）。
- **編集**: 登録内容を変更。グループ紐付けの変更・解除も可能。
- **削除**: 不要になったものを削除。
- **タグ付け**: アイテムにタグ（例: 食品, 洗剤, スーパーA）を付与できる。

### 3.2 タグ管理
アイテムを分類・フィルタリングするためのタグ。
- **タグ作成**: 任意のタグを作成。グループへの紐付けが可能（作成時または後から）。
- **タグ編集**: タグ名の変更、グループ紐付けの変更・解除が可能。
- **タグ削除**: タグを削除。

## 4. 買い物リスト (Shopping List) フロー

実際の買い物に行く際に使用するリストの生成と消化のフロー。

### 4.1 リスト作成プロセス
1. **設定入力**:
   - **グループ選択**: どのグループの買い物かを選択（任意、個人用も可）。
   - **場所（店名）入力**: 買い物をする場所（例: 「スーパー〇〇」）を入力できる。
2. **タグ選択**: 「食品」などのタグを選択し、そのタグが付いた「買いたいもの」を抽出。
3. **アイテム選択 (オプトアウト)**:
   - 抽出されたアイテムがチェックボックス付きで一覧表示される。
   - デフォルトですべて選択状態。
   - 今回は買わないもの（例: 「今日はこのスーパーにはキムチが売っていない」など）のチェックを外して除外できる。
4. **リスト生成**: 選択されたアイテムのみで「買い物リスト」を確定・作成。

### 4.2 買い物実行プロセス
- **カゴ入れチェック**:
  - 店内で商品をカゴに入れたら、アプリ上で該当アイテムのチェックボックスをオンにする。
  - これはあくまで「カゴに入れた（ピックアップした）」状態を示す。
- **購入完了アクション**:
  - 買い物が終わったら「購入済み」ボタンを押す。
  - **日付記録**: ボタン押下時の日時が「購入日」として記録される。
  - チェックが入っている（カゴに入れた）アイテムのみが、システム上で「購入済み」として処理される。
  - チェックが入っていない（買えなかった）アイテムは、「買いたいもの」として未購入のまま残る。

## 5. 購入履歴
- **履歴閲覧**: 購入済みのアイテムをリスト単位またはアイテム単位で閲覧できる。
- **詳細情報**: いつ（購入日）、どこで（場所）、誰が（グループ）、何を買ったかを確認できる。
